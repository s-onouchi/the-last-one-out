# Game Brief: The Last One Out（最後の退勤）

**One-sentence pitch:** 残業で最後まで残った会社員が、消灯・施錠・退勤打刻の手順をこなすうちに、いつものオフィスがじわじわおかしくなっていく、一人称の短編ホラー。

## Core loop
- 退勤チェックリストで次の手順を確認する
- オフィスを歩いて、その手順をこなす（消灯、PCを落とす、窓を閉める、施錠）
- 異変が起きるか、異変に気づく
- 手順が進むほど異変が大きくなり、その中で次の手順へ進む

## Player goal & fail state — what "working" looks like
- 全手順を終えて退勤打刻をし、ビルを出たらクリア（1晩で完結、約20〜30分）
- 追ってくる「何か」に捕まるとゲームオーバー。直前の手順からやり直す

## MVP — what must exist to be the game
- 一人称の移動と視点操作、物を調べる操作
- オフィス1フロア（約40×30m：執務エリア・廊下・会議室・倉庫／資料室・給湯室・トイレ・エレベーター前）
- 退勤チェックリストの画面（手帳風）と、手順の進み具合の管理
- 手順の進行と結びついた異変イベント5〜6個（あらかじめ台本で決めておく）
- 追ってくる「何か」1体と、捕まったときの処理
- VHS風の画面エフェクトと、環境音・効果音
- タイトル → 本編 → クリア／ゲームオーバーの画面の流れ

## Out of scope — not building this
- セーブ機能（1晩を通しで遊ぶ短さなので不要）
- 複数のフロアや、複数の夜
- 戦闘やアイテム集め
- ランダムに起きる異変（すべて台本どおりに起きる）
- ボイスと多言語対応（日本語のみ）

## Build order
1. 一人称の移動と調べる操作、仮のオフィス（箱だけ）
2. チェックリストの進行と手順の実行。異変イベントを1つ、最後まで動く形にする（怖さの核になる部分を最初に確かめる）
3. 残りの異変イベントと、追ってくる「何か」
4. オフィスの作り込み、照明、VHSフィルター、音
5. タイトル・クリア・ゲームオーバーの画面

---
**Who it's for / what they feel:** チラズアートなどの短編ホラーが好きで、20〜30分で1本遊び切りたい人。「いつもの職場が、少しずつ知らない場所になっていく」じわじわした不安を感じてほしい。

**Art & audio direction:** ローポリの3D（モデルは Blender で制作し glTF で書き出す。1単位 = 1m）に、VHSノイズと低解像度フィルター。音は蛍光灯のジーという音やPCのファンなど、静かな環境音が中心。驚かせる演出は数を絞って効かせる。
